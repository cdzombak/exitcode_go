# exitcode_go

Go constants for libc, LSB, BSD, and systemd exit codes, based on [this list compiled in the systemd docs](https://www.freedesktop.org/software/systemd/man/latest/systemd.exec.html#Process%20Exit%20Codes).

## Installation

```shell
go get github.com/cdzombak/exitcode_go
```

## Usage

```go
import (
	"os"

	exitcode "github.com/cdzombak/exitcode_go"
)

func main() {
	if len(os.Args) < 2 {
		os.Exit(exitcode.Usage)
	}
	os.Exit(exitcode.Success)
}
```

## Generated code

`generated.go` is generated by [cdzombak/exitcodes](https://github.com/cdzombak/exitcodes) and should never be edited by hand. To change an exit code or add a new one, edit `exitcodes.tsv` in that repo; a pull request will be opened here automatically with the regenerated file.
